# QuietGuard v1.4.0

Low-memory Windows companion to Microsoft Defender focused on PUP/PUA, adware/browser hijacking, unwanted persistence and suspicious system configuration changes.

## Highlights

- Native Rust/Win32 GUI and low-memory watcher
- Automatic no-key public intelligence updates
- UncheckyAds, FadeMind add.Risk, KADhosts, StevenBlack and YousList context
- Optional ThreatFox/URLhaus caches when an abuse.ch Auth-Key is configured
- Optional ClamAV PUA bridge when ClamAV is already installed
- Optional Google Safe Browsing checks, disabled by default for privacy
- Read-only detection; no automatic deletion or quarantine
